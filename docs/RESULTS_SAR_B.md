# 创新点 B（SAR 尺度自适应回归）结题报告

日期：2026-09-26 ｜ 数据集：VisDrone2019-DET val（548 图 / 38,759 GT）
模型：yolo26n（COCO 预训练微调）｜设置：100 epoch, imgsz=640, batch=16, MuSGD(lr=0.01), seed=0
代码：worktree `wt-exp` 分支 `feat/sar-loss`（commit `dd089c8b8` + `4f5fff008`）

## 1. 一句话结论

**方向正确、机制验证成立，但量级不足：最好配置只带来 +0.3 AP（NMS 头），且落在单种子噪声区间内，不足以作为主创新点。** 其中"给 CIoU 项加尺度权重"被实验证伪（无效甚至略负），可保留为论文中的阴性对照消融。

## 2. 完整实验矩阵（6 次训练，各 100 epoch）

| 实验 | 训练 best mAP50-95 | NMS mAP50 | **NMS mAP50-95** | e2e mAP50 | e2e mAP50-95 |
|---|---|---|---|---|---|
| baseline（sar 全关） | 0.1855 | 0.3280 | **0.1820** | 0.3200 | **0.1770** |
| SAR L1 `w=0.5` | 0.1848 | 0.3260 | 0.1820 | 0.3160 | 0.1760 |
| **SAR L1 `w=1.0`** | **0.1872** | **0.3310** | **0.1850** ⬆ | 0.3170 | 0.1750 ⬇ |
| SAR L1 `w=2.0` | 0.1867 | 0.3300 | 0.1840 | 0.3180 | 0.1760 |
| SAR CIoU `w=1.0`（L1 关） | 0.1844 | 0.3250 | 0.1820 | 0.3170 | 0.1750 |
| SAR L1+CIoU `w=1.0` | 0.1852 | 0.3290 | 0.1830 | 0.3210 | 0.1770 |

固定：`sar_s0=16.0`（参考尺度 px）、`sar_cap=4.0`（最大加权倍数）。

### 关键读法

- **L1 项加权有效但很小**：`w=1.0` 时 NMS 头 0.182 → **0.185（+0.3 AP）**，mAP50 0.328 → 0.331（+0.3）；`w=0.5` 无变化，`w=2.0` 略逊于 `w=1.0` → **存在最优点，形状合理**
- **CIoU 项加权无效**：单独加在 CIoU 上时四项指标三项倒退或持平（0.1820 持平、mAP50 −0.3、e2e −0.2/−0.3）
- **两项叠加会互相抵消**：L1-only 0.185 → L1+CIoU 0.183，同时把 L1-only 造成的 e2e 损失（0.177→0.175）掰回基线（0.177）
- **e2e 头是负向的**：所有 SAR 变体的 e2e mAP50-95 都 ≤ 基线（0.175–0.176 vs 0.177）

## 3. 机制验证（为什么上限这么低）

对 `L1 w=1.0` 的模型单独跑了一遍分尺寸召回（conf=0.25, IoU=0.5）：

| 尺寸(px) | GT 数 | baseline | SAR w=1.0 | Δ |
|---|---|---|---|---|
| 0–8 | 2,424 | 0.061 | 0.060 | **−0.001** |
| 8–16 | 9,545 | 0.222 | 0.223 | +0.001 |
| **16–32** | **14,608** | 0.439 | **0.445** | **+0.006** |
| 32–64 | 9,004 | 0.681 | 0.682 | +0.001 |
| ≥64 | 3,178 | 0.849 | 0.851 | +0.002 |

- 增益确实落在 **GT 最多的一档（16–32px）**，说明机制按设计生效，不是随机波动
- **0–8px 一档完全没动**：640 输入下这些目标（占 GT 6.3%）不足一个 P3 网格（8px），**特征金字塔表达不了，改损失权重救不回来** —— 这是表示侧的天花板，不是损失侧的问题

### 为什么 CIoU 加权注定冗余

CIoU（`1 − CIoU`）**本身已经尺度敏感**：同样偏 1px，4px 框的 IoU 掉到 0.14，64px 框几乎无感。而 DFL-free 后的 L1 是**图像归一化坐标**下算的，1px 误差对两种尺度的贡献完全相同 —— **只有 L1 才是真正尺度无关的那一项**。再给 CIoU 乘尺度权重等于重复强调它已隐含的信息，因此无效。

> 这条阴性结果有论文价值：它把"病根在 L1 项"这件事**证死**了，排除了"IoU 类损失也能改"的质疑。

## 4. 判定与去向

| 项目 | 判定 |
|---|---|
| 能否作为主创新点 | ❌ 不行。+0.3 AP 单种子，落在噪声内 |
| 能否作为附加贡献 | ⚠️ 需要至少 3 种子确认；即便成立也偏薄 |
| 能否作为论文消融/动机 | ✅ 可以：〈L1 加权重有效 / IoU 加权重冗余〉这组对照 + "68.6% 目标 <32px、@640 中位仅 11.3px" 的动机数据 |
| 代码是否保留 | ✅ 保留。3 文件 +46/−4 行，4 个超参默认全 0 → **逐位等价原版、推理零开销**，可作 ablation 开关 |
| 下一步 | 转 **创新点 A（DHCD 双头一致性蒸馏）**：靶子是结构性的（e2e 头低 0.5 AP，小目标召回低 2–5 点），且为 YOLO26 独有结构 |

### 若要抢救 B（备选，非首选）

1. **多种子**（baseline 与 `w=1.0` 各 3 种子，约 11h）→ 确认 +0.3 是否真实
2. **换分辨率**（960）→ 小目标占比结构改变，重加权可能放大；但代价 3.5h 且仍可能只是 +0.3 量级
3. **更长训练**（300 epoch）→ 未知，需要实跑验证
